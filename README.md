# engineering-problems

This repository contains a set of JavaScript-based engineering and systems problems designed to practice common interview-style and real-world technical challenges. Each folder focuses on a different concept such as data structures, performance optimization, memory management, or concurrency.

## Repository overview

- Bloom Filter: probabilistic membership checking with bit arrays and hash functions
- Circular Buffer: fixed-size ring buffer for FIFO streaming or queue workloads
- Custom Object Pool: reusing objects to reduce allocation overhead
- Efficient Diff Algorithm: comparing sequences and computing meaningful differences
- Efficient Search Index: inverted index and ranked search implementation
- Large File Processing Simulator: comparing generator-based streaming vs full in-memory loading
- Memory Efficient Cache: compact cache design and eviction strategies
- Memory Leak Detector: detecting unbounded memory growth patterns
- Performance Benchmark Framework: benchmarking code execution and comparing alternatives
- Worker Thread Task Processor: parallel task execution using Node.js worker threads

## What this repo is for
The projects here are useful for learning and practicing:
- algorithm design
- system trade-offs
- performance analysis
- memory efficiency
- concurrency and worker-based execution
- practical engineering problem-solving in JavaScript

## Notes
Most folders are self-contained and can be run independently with Node.js. The README files inside each folder explain the goal and problem statement in a short, focused way.
